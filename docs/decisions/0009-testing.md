# ADR-0009: テストは vitest ブラウザモード

- 状態: 採択
- 日付: 2026-09-10

## 決定

- テストは vitest のブラウザモード（Playwright 経由の実ブラウザ）で全部を実行する
- JS なしテストは「Custom Element の定義モジュールを読み込まない状態で HTML を描画し、目的の操作が成立する」ことを検証する方式とする

## 理由

- このライブラリの価値は、jsdom が省略している部分（ネイティブ要素の振る舞い、`<details name>` の排他、popover、キーボード、フォーカス）にある。模擬環境で通しても検証したことにならない
- 2 つの環境を併用すると保守費用が素朴さに反する。テスト数が少ないうちは起動時間も問題にならない
- Playwright の `javaScriptEnabled: false` は vitest 自身の実行と両立しないため、定義モジュールを読み込まない方式で代替する

## 却下した選択肢

- jsdom / happy-dom のみ: APG の検証が形だけになる
- 併用: 環境が 2 つになる
