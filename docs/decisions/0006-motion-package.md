# ADR-0006: アニメーションは独立パッケージとして枠だけ予約

- 状態: 採択
- 日付: 2026-09-10

## 決定

- `@flat-html/motion` を同じモノレポに独立パッケージとして置き、当面は枠だけ予約する
- JS でしかできないものと CSS 標準でできるものを切り分け、後者の素朴なものだけ作る
- CSS 標準でできる部分を css と motion のどちらに置くかの線引きは、中身を作るときに改めて決める

## 理由

- JS でしかできない部分（Web Animations API、時間軸の同期）が入ると、css パッケージの「読み込むだけ」という性質を壊す。最初から別にして css の純度を守る
- 枠だけなら費用はディレクトリ 1 つと package.json 1 つ

## 関連

- 文書間の View Transitions（CSS の `@view-transition`）と `<link rel="expect">` はこのパッケージの守備範囲
