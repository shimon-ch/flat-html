# ADR-0012: 式は `{{ }}` と `<template if/each>` の最小範囲

- 状態: 採択
- 日付: 2026-09-10

## 決定

- 変数展開は `{{ title }}`。テキストと属性値の両方で使える
- 条件と繰り返しは `<template if="…">` と `<template each="item of items">`。`<template>` は出力で消える
- 式はプロパティ参照（`item.title`）、比較（`==` `!=`）、否定（`!`）、論理（`&&` `||`）まで。関数呼び出し、算術、代入は許さない
- コンポーネントの中から見えるのは自分の引数だけ。ページのデータはページのテンプレートが引数として明示的に渡す
- `{{ }}` は常に HTML エスケープする。生の HTML は `<template html="…">` でだけ差し込む

## 理由

- `{{ }}` は学習費用が最も低い
- `<template>` は HTML として有効で、解析時に中身が不活性になる。`parse5` に載せる ADR-0008 と噛み合う
- 式の範囲を狭く固定することで、テンプレートにロジックが流れ込むのを構造で防ぐ。これが「ツールはデータの形を知らない」の実体
- 内容を slot で渡す指針（ADR-0010）により、`{{ }}` の出番はデータ駆動の繰り返しに縮む

## 却下した選択肢

- 任意の要素に `if` `each` 属性: 将来の HTML 属性と衝突しうる
- `{{#if}}`: テキストの中に構造を隠す
