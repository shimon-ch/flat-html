# ADR-0002: flat-html の責務は展開と集約まで

- 状態: 一部置換済み（「核は Vite に依存しない API と CLI」の部分は ADR-0020 で置換。責務の範囲は有効）
- 日付: 2026-09-10

## 文脈

flat-html は「HTML の解析から変換までの build 工程を、Rust を部分的に使って速くする npm パッケージ」である。crates.io に出す意図はない。責務の境界を決める必要がある。

## 決定

- 責務は次の 2 つに限る
  - 展開: タグ参照、差し込み口、属性による引数、最小の式
  - 集約: コンポーネントが参照した CSS と JS を `<head>` へ集める
- HTML の最適化（圧縮、属性整理、資産のハッシュ付与）は持たない
- 核は Vite に依存しない API と CLI。Vite プラグインは薄い皮
- 開発スタックは Vite+ で統一する

## 理由

- 展開と集約は同じ 1 回の走査で済む。集約がないと、振る舞い付きコンポーネントの JS をページに載せる手段が別途要る
- 最適化は Vite が既に担っている。持ち込むと素朴さの線を越える
- Vite 非依存なら、テストを Vite なしで書け、Rust 部分の境界が明確になり、他のビルド環境で使う道を閉じない

## 却下した選択肢

- 展開だけ: JS の配信経路が別途必要になる
- 最適化まで: Vite と重複する
- Vite プラグイン専用: テストと境界が Vite に縛られる

## 影響

- Vite プラグインは「変換後の HTML を Vite に渡し、監視対象を登録する」だけになる
- Vite+ はベータ。不具合で止まった場合は勝手に素の Vite へ戻さず、報告して指示を仰ぐ（ADR-0007）
