# ADR-0018: 文書の置き場

- 状態: 採択
- 日付: 2026-09-10

## 決定

- `docs/design.md`: 思想の本文
- `docs/decisions/`: 決定を 1 件 1 ファイルの ADR で。覆すときは新しいファイルを足し、古いものは「置換済み」にして残す
- `docs/glossary.md`: 用語集
- `docs/history/`: 検討の経緯。旧 `design-plan.md` はここへ移す
- 各コンポーネントの仕様 4 項（ADR-0004）は、そのコンポーネントのディレクトリの `spec.md` に置く

## 理由

- 決定と経緯を物理的に分けることで「今どう決まっているか」だけを読める場所ができる
- なぜそう決めたかを残さないと、次の読み手が同じ誤解を繰り返す
- 仕様がテンプレートとテストから離れると必ず古くなる
