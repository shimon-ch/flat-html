# ADR-0026: 見本サイトは、ビルド済みのファイルだけを置く公開リポジトリから配信する

- 状態: 採択（ADR-0025 の「見本サイトの配信は止める」を置換。リポジトリを非公開に保つ判断は有効）
- 日付: 2026-10-19

## 文脈

ADR-0025 でリポジトリを非公開のまま詰めると決めた後、所有者から見本サイトを GitHub Pages で公開し URL を出すよう依頼があった。

このリポジトリで Pages を有効にしようとすると、GitHub は「Your current plan does not support GitHub Pages for this repository.」（HTTP 422）を返した。無料プランでは、Pages は公開リポジトリでしか使えない。取れる道は 3 つあった。

- このリポジトリを公開する: ADR-0025 のとおり、履歴と PR の参照から旧メールが読める
- GitHub Pro に上げる: 課金は所有者の判断
- ビルド済みのファイルだけを別の公開リポジトリに置き、そちらの Pages で配信する

## 決定

- 公開用リポジトリ `shimon-ch/flat-html-site` を作り、ビルド済みのサイトのファイルだけを置く。そのリポジトリの Pages（`main` ブランチの直下から配信）で出す。URL は `https://shimon-ch.github.io/flat-html-site/`
- ソース、履歴、PR、issue はこのリポジトリに非公開のまま残す
- サイトの配信パスは環境変数 `SITE_BASE` で渡す。CI は `/flat-html-site/` を渡す。設定ファイルには配信先を書き込まない
- 非公開リポジトリの `pages.yml` が、ビルドと Lighthouse の予算検査（ADR-0021）を通った後に、公開用リポジトリへ push する。予算で落ちたら配信しない
- push には公開用リポジトリの書き込み鍵（デプロイキー）を使う。鍵の登録は所有者が行う。鍵が登録されてリポジトリ変数 `PAGES_DEPLOY` が `true` になるまで、配信の段は飛ばされる
- 公開用リポジトリのコミットは、作者を noreply か `github-actions[bot]` にし、メッセージは `deploy <コミットの短いハッシュ>` だけにする

## 表に出るもの

- ビルド済みの HTML、CSS、JS と `.nojekyll`
- 配信先の URL に含まれる GitHub のユーザー名
- 見本サイトのフッターにあった GitHub へのリンクは外した。非公開リポジトリを指していて訪問者には 404 になり、非公開リポジトリの名前を明かすだけだったため

## 却下した選択肢

- このリポジトリを公開する: 旧メールが読める（ADR-0025）
- GitHub Pro に上げる: 課金は所有者が決める。上げた場合は、このリポジトリの Pages に戻せる
- Cloudflare Pages など別の配信先: アカウントの作成と鍵の登録が要り、GitHub の外に情報を置くことになる

## 引き受ける制約

- 公開用リポジトリの履歴に、配信のたびにコミットが積まれる
- 鍵が登録されるまでは自動で配信されない。最初の配信は手元から行った
