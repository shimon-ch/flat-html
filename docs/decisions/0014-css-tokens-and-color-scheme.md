# ADR-0014: トークンは最小粒度、明暗は light-dark() で一元化

- 状態: 一部置換済み（切り替え要素の形は ADR-0022 で置換。トークンと明暗の一元化は有効）
- 日付: 2026-09-10

## 決定

- トークンはカスタムプロパティを `:root` に `--flat-*` で定義する。消費側は site 層で同じ名前を上書きしてテーマを変える
- 粒度は最小から始める。色は背景・前景・強調・境界の 4 系統、余白は 1 つの基準値からの倍数、角丸と書体は各 1 つ。合計 10 前後
- 明暗は `color-scheme` と `light-dark()` で 1 つの定義にまとめ、`prefers-color-scheme` の分岐を書かない
- ページが対応する配色は `<meta name="color-scheme" content="light dark">` で宣言し、CSS パッケージはそれに従う
- 明暗の切り替え要素を最初から用意する。基礎は `<input type="checkbox" switch>` と `:root:has(:checked)`。Switch 属性は「対応ブラウザが足す強化」、選択の保存と次ページへの引き継ぎは「JS が足す強化」
- `@property` はアニメーションや型付けが要る場面で、`prefers-reduced-motion` は動きを持つすべての箇所で使う

## 理由

- テーマの変更点を「名前を上書きする」1 種類に絞れる
- 段階を増やすほど「どの段階を使うか」の判断がコンポーネントごとに要り、規約を生む。足りなくなった時点で足す方が安い
- `light-dark()` は Baseline 2024 で、明暗を 2 箇所に書く構造そのものを消せる
- `<meta name="color-scheme">` は HTML 標準の宣言方法で、独自の宣言方法を持たずに済む
