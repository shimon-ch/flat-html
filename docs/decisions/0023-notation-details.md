# ADR-0023: 記法の細目（実装で確定した解釈）

- 状態: 採択（ADR-0010 / 0011 / 0012 / 0013 / 0019 を補う。置換はしない）
- 日付: 2026-09-21

## 文脈

ADR-0010 から 0019 は記法の骨格を決めたが、実装すると骨格だけでは決まらない細目が出た。実装が黙って決めた振る舞いを文書に引き上げ、次に読む人が実装を読まなくても分かるようにする。

## 決定

### 参照と引数（ADR-0010 を補う）

- 解決できない `flat-*` 参照は**例外にする**。テンプレートのパスと行を添えて失敗させ、黙って無視しない。誤字が出力から静かに消えるのを避けるため
- 循環参照は、展開中のテンプレート名のスタックで防ぐ。スタックに載っている名前は展開せず、要素のまま残す。これは「テンプレート自身の出力に含まれる同名タグを Custom Element として残す」という要求と同じ仕組みで、a → b → a のような間接的な循環も止まる
- 集約の対象になる資産要素（`<link rel="stylesheet|modulepreload|preload">` と `src` 付き `<script type="module">`）は、テンプレートの最上位にあっても**出力の根要素とみなさない**。`data-flat` を付けず、引数も透過しない。参照側の `id` が `<link>` に乗るのを避けるため
- テンプレートの根がさらに別の `flat-*` の展開結果である場合、`data-flat` は**外側のコンポーネントの名前が勝つ**

### 差し込み（ADR-0011 を補う）

- 名前なしの差し込みが空白テキストだけなら、差し込みなしとみなして既定内容を残す。整形された HTML で既定内容が消えるのを避けるため。shadow DOM の厳密な挙動とは異なる
- 同名の `<slot>` が複数あれば、先頭だけが受け取る
- 差し込み先のない子要素は捨てる

### 式（ADR-0012 を補う）

- `==` と `!=` は**型も含めて比べる**（JavaScript の `===` / `!==` と同じ）。引数は常に文字列なので、`count == 3` は `count="3"` でも偽になる。数の比較が要るなら、ビルドスクリプト側で数として渡す
- 括弧 `( )` によるグループ化を許す。演算ではないので ADR-0012 の禁止（関数呼び出し・算術・代入）には当たらない
- `&&` と `||` は JavaScript と同じく**被演算子を返す**。真偽値には変換しない
- `each` の対象が配列でなければ例外にする。`null` と `undefined` は空の繰り返しとして許す
- if / each / html のいずれも持たない素の `<template>` の中身は**不活性**として扱う。式も参照も処理しない

### 集約（ADR-0013 を補う）

- 重複除去の鍵は「種類 + URL」。`<link rel="modulepreload" href="/a.js">` と `<script type="module" src="/a.js">` は別物として両方残す
- `<head>` がない断片の変換では移動しない

### ページとレイアウト（ADR-0019 を補う）

- `<title>`、`<meta charset>`、`<meta name="viewport">` は、ページ側の先頭を残して他を全部消す。ページになければレイアウト側の先頭
- レイアウトの循環は、解決済みパスの集合で検出して例外にする
- `<link rel="layout">` の `href` と `<slot name>` に `{{ }}` は使えない。レイアウトの解決と差し込みは式の評価より前に行うため

### 変換の API（ADR-0020 を補う）

純粋関数 `transform` の引数に、骨格の決定にはなかったものを 3 つ足した。

- `resolveLayout(href, fromPath)`: レイアウトは参照名でなく相対パスで指すので、`resolve` と分ける
- `path`: 入力のファイルパス。エラー表示とレイアウトの相対解決に使う
- 戻り値の `layouts`: 解決したレイアウトの一覧。ADR-0019 の解決一覧に含める

## 既知の制約

- `<table>` の直下など、HTML の解析でノードが外へ追い出される位置（foster parenting）に置いた `flat-*` 参照は、仕様どおり親の外へ出る。ブラウザと同じ挙動なので直さない
