# ADR-0001: リポジトリはライブラリ群のモノレポ flat-html

- 状態: 採択
- 日付: 2026-09-10

## 文脈

当初は個人サイトの設計文書として始まったが、実体はコンポーネントライブラリ群だった。ツール、コンポーネント、CSS、将来のアニメーションが同じ人の手で同時に育つ段階にある。

## 決定

- このリポジトリを `flat-html` と名付け、ライブラリ群のモノレポとする
- npm スコープは `@flat-html/*`
- 個人サイトは別リポジトリに置き、npm 経由で消費する
- ライブラリ群の見本サイト `apps/site` はこのリポジトリに置き、GitHub Pages に出す

## 理由

- サイト固有の都合がライブラリに逆流しない境界を、リポジトリの境界で物理的に作る
- 将来ライブラリ群だけを公開する際にサイトを切り離す作業が要らない
- `@flat-html` スコープと GitHub の `flat-html` が空いており、追加の命名が不要
- 「平坦」「素朴」の含意を一族全体で共有できる

## 却下した選択肢

- 個人サイトも含む単一モノレポ: 逆流の入口になる
- `flat` を一族名にする: `flat-ui` が npm で取られており、コンポーネントの名前を別に考える必要が出る

## 影響

- 見本サイトはこのリポジトリ内で唯一の消費者になる。見本サイトの都合で API を足したくなったら、一般の消費者にも要るかを一度問う
- GitHub Pages を使うには公開リポジトリか有料プランが要る（ADR-0017）
