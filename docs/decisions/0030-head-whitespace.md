# ADR-0030: `<head>` に要素を出し入れするときは、前の空白も一緒に動かす

- 状態: 採択（ADR-0013 / ADR-0019 / ADR-0023 を補う。置換はしない）
- 日付: 2026-11-02

## 文脈

ページとレイアウトの合流（ADR-0019）と資産の集約（ADR-0013）は、`<head>` の中で要素を外し、別の位置へ入れる。整形して書いた HTML では、要素の前に改行と字下げだけのテキストがある。要素だけを動かすと、そのテキストは元の位置に残り、入れた先には付かない。

見本サイトの出力では、`<head>` に空行が並んだ。

- 重複除去で消したレイアウト側の `<title>` などと、`<link rel="layout">` の跡に、改行と字下げが残る
- ページ側 `<head>` の子は空白のテキストごと、レイアウトの `<head>` の `</head>` の前の改行より後ろへ入る
- 集約した資産も `</head>` の前の改行より後ろに入り、字下げなしで並ぶ

描画は変わらないが、出力を読む人と差分で確かめる人の妨げになる。

## 決定

- `<head>` の中で要素を外すとき（重複除去、`<link rel="layout">` の除去、集約のための移動、描画や展開で要素が何もない結果か、空白だけのテキストの結果に置き換わるとき。偽の `<template if>`、結果が空の `<template each>` と `<template html>`、中身が空の `<template if>`、何も出さない参照、空白だけを出す参照など）は、その要素の直前にある空白だけのテキストノードも一緒に外す
- `<head>` へ入れるとき（ページ側 `<head>` の子の移動、集約した資産の移動）は、`<head>` の末尾にある空白だけのテキスト（`</head>` の前の改行と字下げ）の前に入れ、直前に改行と `<head>` の字下げを置く
  - 字下げは、`<head>` の最初の子ノードが改行を含む空白だけのテキストなら、その最後の改行より後ろとする。要素を出し入れする前に求める
  - 最初の子ノードが空白だけのテキストでないとき（詰めて書いた `<head>` など）や、その空白が改行を含まないとき（1 行で書いた `<head>` など）は、字下げを求めず、空白を足さない
- ページ側 `<head>` からレイアウト側へ移すとき、空白だけのテキストノードは移さない。コメントは移す
- `<head>` の中かどうかは、外す要素の親で判定する
- `<body>` の中の空白には触らない。`<body>` から `<head>` へ集約する資産は、要素だけを外す
- 要素の順序と、どの要素を残すか（ADR-0023）は変えない

## 理由

- `<head>` の中の空白は描画されず、意味を持たない。HTML の解析では、`<head>` の直下に置けるテキストは空白だけで、空白以外の文字が来た時点で `<head>` は閉じて `<body>` が始まる。`<head>` 自体も描画されない（既定のスタイルで `display: none`）
- ADR-0013 の「暗黙の動作は移動と重複除去の 2 つに限る」は、書いた HTML の意味についての制約である。移動と除去に付随する空白の扱いは意味を変えないので、新しい動作に数えない
- `<body>` の中の空白は、インライン文脈では語の間の空きとして描画される。資産を外した跡の空白まで消すと、前後のインライン要素が詰まり、見た目が変わりうる
- 字下げは書き手が `<head>` に使ったものにそろえる。設定を増やさない

## 却下した選択肢

- 直列化の前に `<head>` 全体の空白を整形し直す: flat-html が触っていない箇所まで、利用者が書いた空白を書き換える
- 何もしない: 描画は変わらないが、出力の `<head>` に空行が並び続ける

## 影響

- 整形して書いたページとレイアウトでは、出力の `<head>` に要素が 1 行に 1 つずつ並び、`</head>` の前の字下げが保たれる
- 詰めて書いた `<head>` と 1 行で書いた `<head>` には、改行も字下げも足さない
- レイアウトの `<head>` が空でも、`<head>` の直後に改行があれば、その後ろの空白が字下げになり、ページ側の要素は `</head>` と同じ字下げで 1 行ずつ並ぶ。`<head></head>` と書いた空の `<head>` では、ページ側の要素は空白なしで並ぶ
- `<body>` から集約した資産の跡には、改行と字下げが残る
- Vite が本番ビルドで `</head>` の直前に差し込む資産は、Vite が `</head>` の前の字下げに 1 段足して字下げする。flat-html は `</head>` の前の字下げを保つだけで、差し込みには関わらない
