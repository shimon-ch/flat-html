# ADR-0013: 集約は普通の `<link>` と `<script>` を head へ移すだけ

- 状態: 採択
- 日付: 2026-09-10

## 決定

- 集約に新しい語彙を作らない。テンプレートに普通の `<link rel="stylesheet">`、`<script type="module">`、`<link rel="modulepreload">`、`<link rel="preload">` を書く
- flat-html は展開後にそれらを `<head>` の末尾へ移し、同じ URL のものは最初の 1 つだけ残す
- 暗黙の動作はこの移動と重複除去の 2 つに限る

## 理由

- 書く側にとっては「HTML を書いただけ」で、移動と重複除去は書いた HTML の意味を変えない
- `<link>` も `<script type="module">` も body に書いて有効だが、CSS が body にあると描画後に見た目が変わる瞬間が出るため `<head>` へ移す
- 参照したコンポーネントの資産だけがページに載るので、使わないコンポーネントの CSS と JS は入らない

## 却下した選択肢

- `<push>` と `<stack>`: 資産以外を送りたい場面（meta など）が出るまで不要
- ファイル名規約による自動連結: ファイルの有無で出力が変わる暗黙の依存
