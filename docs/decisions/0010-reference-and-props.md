# ADR-0010: 参照名は出力要素名と同じ、属性はそのまま引数

- 状態: 採択
- 日付: 2026-09-10

## 決定

- 参照タグの名前は出力される要素名と同じ `flat-*`。Custom Element を持つものは展開後も `<flat-tabs>` が残り、ネイティブ要素だけのものは参照タグが消えて `<details name>` などに置き換わる
- 属性は宣言なしにそのまま引数となる。テンプレートが使わない属性は出力の根要素へ透過する
- 展開は 1 回の走査で行い、結果を再走査しない
- flat-html はテンプレート出力の最上位要素すべてに `data-flat="<コンポーネント名>"` を自動で付ける。自動で足す属性はこれ 1 つに限る
- 内容は slot で渡し（ADR-0011）、属性は変種や識別子など内容でないものに限る

## 理由

- 書く側の語彙が 1 つで済む。参照名と実行時の名前が別だと、どちらの話をしているか混乱する
- 参照名が消えるコンポーネントでも、`data-flat` が CSS と開発者ツールの足がかりになる。仕様 4 項の「出力の根要素」と組で誤解を防ぐ
- 宣言なしの引数は書く量が減り、透過で `id` や `aria-*` を消費側から足せる
- `<flat-card title="About">` より `<flat-card><h2 slot="title">About</h2></flat-card>` の方が、見出しが `<h2>` として意味を保ったまま届く

## 却下した選択肢

- 接頭辞で消えるものと残るものを区別（`x-` と `flat-`）: 語彙が 2 つになる
- テンプレート側で引数を宣言: 型検査や必須検査が要るときに足す
- 常に包みを残す: `<ul>` 直下に `<li>` 以外が残るなどセマンティクスが壊れる
