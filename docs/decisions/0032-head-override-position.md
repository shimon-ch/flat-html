# ADR-0032: ページの `<title>` と `<meta charset>` と `<meta name="viewport">` は、レイアウトの同じ種類の要素の位置に入る

- 状態: 採択（ADR-0019 / ADR-0023 を補う。置換はしない）
- 日付: 2026-11-02

## 文脈

ページとレイアウトの合流（ADR-0019）では、`<title>`、`<meta charset>`、`<meta name="viewport">` を、ページとレイアウトにまたがって 1 つに揃える。ページ側に同じ種類の要素があれば、ページ側の先頭を残す（ADR-0023）。一方、ページの `<head>` の子は、レイアウトの `<head>` の末尾へ移る。

この 2 つが重なると、残したページ側の要素は、レイアウトの `<head>` の末尾に出る。レイアウトが `<meta charset>` を先頭に置き、その後に `<meta name="color-scheme">` などを並べていても、出力の `<meta charset>` はそれらより後ろに来る。見本サイトの出力では、`<meta charset>` が `<meta name="color-scheme">` の後ろにあった。

HTML 仕様は、文字コードの宣言を含む要素を、文書の先頭 1024 バイト以内に完全に収めるよう求める（[Specifying the document's character encoding](https://html.spec.whatwg.org/multipage/semantics.html#charset)）。レイアウトの `<head>` が大きいと、末尾へ移った `<meta charset>` はこの範囲の外へ出うる。

## 決定

- `<title>`、`<meta charset>`、`<meta name="viewport">` のそれぞれについて、ページ側の要素を残し、レイアウトの `<head>` の直下にも同じ種類の要素があるときは、ページ側の要素をその最初の要素の位置へ移してから、他の同じ種類の要素を消す。ページの値が、レイアウトの位置を引き継ぐ
- レイアウトの `<head>` の直下に同じ種類の要素がなければ、ページ側の要素は従来どおり、ページの `<head>` の他の子と一緒にレイアウトの `<head>` の末尾へ移る
- ページ側に同じ種類の要素がなければ、従来どおりレイアウト側の先頭を残す
- 1 つに揃える候補は、式の評価より前に探す。素の `<template>` の中は数えず（ADR-0023）、`<template if/each/html>` の中は数える。`<template if/each/html>` の中の要素は位置の基準にせず、ページ側の要素をその中へは入れない。残すページ側の要素が `<template if/each/html>` の中にあるときも、位置は引き継がない
- ADR-0023 の「先頭」は、ページの `<head>` の直下にある最初の候補、ページ側の最初の候補、レイアウトの `<head>` の直下にある最初の候補、レイアウト側の最初の候補の順に、最初に見つかったものとする。`<template if/each/html>` の中の候補は式の評価で消えうるので、直下の候補を先に選ぶ
- 移すときの空白は ADR-0030 に合わせる。レイアウト側の要素の直前の空白をそのまま使い、ページ側の要素の跡には空行を残さない
- 多段のレイアウトでは、合流のたびにこの規則を当てる。ページの値は、外側のレイアウトの位置へ順に移る
- どの要素を残すか（ADR-0023）は変えない。変わるのは、残した要素の位置だけである

## 理由

- HTML 仕様は、文字コードの宣言を文書の先頭 1024 バイト以内に完全に収めるよう求める。レイアウトの書き手が `<meta charset>` を `<head>` の先頭に置けば、ページが自分の `<meta charset>` を書いても、出力の `<meta charset>` は先頭に残る
- レイアウトの書き手が決めた順序を保てる。レイアウトは文書の骨格を決める側で、ページは値を差し替える側である。ページが値を差し替えても、要素の並びはレイアウトに書いたとおりになる
- 3 種類に同じ規則を当てるので、`<meta charset>` だけの特別扱いが要らない

## 却下した選択肢

- `<meta charset>` だけを常に `<head>` の先頭へ移す: 1024 バイトの要件は満たすが、レイアウトの書き手が決めた順序を崩す。`<meta charset>` だけの特別扱いが増える
- 何もしない: 出力の `<meta charset>` が、レイアウトの他の要素より後ろに出る。レイアウトの `<head>` が大きいと、先頭 1024 バイトの外へ出うる

## 影響

- 見本サイトの出力では、`<meta charset>` が `<head>` の先頭に戻る。`<meta name="viewport">` と `<title>` も、レイアウトに書いた位置に入る
- `<meta name="description">` のように 1 つに揃えない要素は、従来どおりレイアウトの `<head>` の末尾へ移る
- レイアウトが `<meta charset>` を先頭に置かなければ、出力でも先頭には来ない。1024 バイトの要件を満たす位置に置くのは、レイアウトの書き手である
- 既知の制約: ページにない種類の要素を、レイアウトが `<template if="x">` と `<template if="!x">` に分けて書くと、合流で前の方だけが残り、x が偽のときはその要素が出力に出ない。合流が式の評価より前に行われるためで、この ADR より前からある制約である
