# ADR-0004: 各コンポーネントに仕様 4 項と JS なしテストを必須にする

- 状態: 採択
- 日付: 2026-09-10

## 文脈

「UI の目的を JS なしの HTML で果たせるか」がこのライブラリの独自の原則だが、文書化されていないと読み手が誤解する。実際に、いいねボタンの例が「サーバーがないと意味がない」と読み違えられた。

## 決定

各コンポーネントは `spec.md` に次の 4 項を必ず書く。

1. 目的: この UI が利用者に何をさせるためのものか
2. JS なしで到達できる状態: HTML だけで目的のどこまでが成立するか
3. JS が足す強化: JS があるとき何が加わるか。なければ「なし」。対応ブラウザだけが足す強化もここに書く
4. 出力の根要素: 展開後にどの要素が最上位になるか。参照名が出力に残らない場合はそれを明記する

テストは次の 2 種を必須とする。

- JS なしテスト: Custom Element の定義モジュールを読み込まない状態で HTML を描画し、目的の操作が成立することを検証する
- APG テスト: APG が定めるキーボード操作とフォーカス管理を検証する

## 理由

- 4 項を書く行為自体が「本当に JS が要るか」を毎回問い直す装置になる
- 出力の根要素を書くことで、参照名が消えるコンポーネントの CSS や配置の誤解を防ぐ
- JS なしテストは、Custom Element の定義が届く前でも「壊れて見えない」ことの検証を兼ねる

## 影響

- `spec.md` はテンプレートとテストの隣に置く（ADR-0018）
