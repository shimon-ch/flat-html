# ADR-0011: 差し込みはネイティブ slot と同じ語彙

- 状態: 採択
- 日付: 2026-09-10

## 決定

- テンプレート側は `<slot>` と `<slot name="…">`。`<slot>` の中身は差し込みがないときの既定内容
- 消費側は子要素に `slot="…"` 属性を付ける。属性のない子要素は名前なしの `<slot>` へ
- 差し込まれた要素の `slot` 属性は出力で消す
- ビルド時の差し込みは shadow DOM の投影と違い、要素を実際に移動する。この差を仕様に明記する

## 理由

- ブラウザの shadow DOM と同じ心的模型なので、新しい語彙がない
- ADR-0003 で light DOM を既定にしたため、shadow DOM の slot を実際に使う場面が少なく、語彙を転用しても衝突しない
- 出力に shadow root はないので `slot` 属性を残す意味がなく、残すと読む人が立ち止まる

## 却下した選択肢

- `<slot:name>` と `<fill:name>`（posthtml-component の語彙）: 独自語彙
