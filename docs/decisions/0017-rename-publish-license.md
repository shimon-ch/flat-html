# ADR-0017: 改名は今、公開は見本サイトを出す時点、MIT

- 状態: 一部置換済み（公開の時期は ADR-0025 で保留し、ADR-0028 で公開に戻した。改名と MIT は有効）
- 日付: 2026-09-10

## 決定

- リポジトリを `personal-site-design` から `flat-html` に改名する（2026-09-10 に実行済み。旧 URL は GitHub が転送する）
- 公開は、最初の縦切りが通って見本サイトを GitHub Pages に出す時点で行う
- ライセンスは MIT

## 理由

- これから作るディレクトリとパッケージの名前が全部 `flat-html` を前提にする
- 見本サイトを Pages に出すには公開が要る。設計文書だけの段階で公開しても得るものが少ない
- npm に出すライブラリなら MIT が既定

## 記録（未決定）

- form を受ける素朴なサーバーが必要になった場合は Cloudflare Workers + Hono を第一候補とする。HTML の form 送信はページ遷移なので別オリジンでも CORS の制約を受けず、303 で見本サイトに戻せる
- 見本サイトの配置先は当面 GitHub Pages
