# ADR-0005: CSS は class なしで使える独立パッケージ

- 状態: 採択
- 日付: 2026-09-10

## 決定

- `@flat-html/css` は class なしで使える独立パッケージ。正しい HTML を書けばそのまま整う
- セレクタは要素と ARIA 状態を基本にする（`details[open]`、`[role=tab][aria-selected=true]` など）
- 見た目の変種は data 属性で表す。クラスは使わない
- 層は `@layer reset, base, components, site` の順に固定する
- コンポーネント（elements）は css に依存する。逆は起きない
- 消費側の逃げ道は `@layer` の順序（site 層が必ず勝つ）で足りるとし、専用の打ち消し属性は具体的な必要が出るまで作らない

## 理由

- 「セマンティックであることが最優先」なら、正しい HTML を書いた人が何も足さずに恩恵を受けるべき
- 要素と ARIA 状態に当てると、スタイルがマークアップの正しさを検証する側に回る。`aria-selected` を書き忘れれば見た目も変わらない
- クラスは意味を持たない名前を増やすだけで、素朴さと相性が悪い

## 却下した選択肢

- クラス名の規約: 名前の学習費用と、マークアップの正しさから独立してしまう問題
- コンポーネントに付随する CSS のみ: 素の HTML を書く人が恩恵を受けられない
