# ADR-0007: 操作は vp 経由、最初の縦切りは accordion

- 状態: 採択
- 日付: 2026-09-10

## 決定

- パッケージ管理の操作は `vp`（`vp install`、`vp run` など）で行い、直接 pnpm を叩かない。`vp env` が選ぶ下層は pnpm
- 最初の縦切りは Exclusive Accordion（`<details name>`）を 1 つ、テンプレート、CSS、APG テスト、JS なしテスト、見本サイトへの掲載まで通す
- 2 つ目は明暗の切り替え要素（ADR-0014）
- Vite+ のベータの不具合で止まった場合は、勝手に素の Vite に戻さず、状況を報告して指示を仰ぐ

## 理由

- accordion はネイティブ要素だけで目的を果たせるので JS が要らず、CSS の状態セレクタ、APG の要件、JS なしテストのすべてを最小の実装で試せる。ADR-0003 から 0005 が実際に成立するかを一度に検証できる
- 明暗切り替えは仕様 4 項がきれいに当てはまる例で、原則の見本になる
