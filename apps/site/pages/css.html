@flat-html/css

このページの HTML には class 属性が 1 つもない。正しい要素を正しく書けば、 @flat-html/css がそのまま整える。明暗は OS の設定に追従する（<meta name="color-scheme" content="light dark">）。

見出しと段落

三番目の見出し

段落。リンク、強調、弱い強調、code、Ctrl + K、出力 を含む。

四番目の見出し

引用。左に境界線が付く。

フォーム部品

入力

details

同じ name を持つ <details> は排他的に開く。JS は使っていない。

class なしで本当に足りるのか

要素と ARIA 状態に当てると、スタイルがマークアップの正しさを検証する側に回る。aria-selected を書き忘れれば見た目も変わらない。

見た目を変えたいときは

site 層に書く。層の順序は @flat-html/css が固定していて、後の層が必ず勝つ。

変種はどう表すか

button[data-variant="primary"] のように data 属性で表す。

dialog

Invoker Commands（commandfor と command）で開く。JS は使っていない。

ダイアログ

背景が暗くなり、フォーカスがここに閉じ込められる。Esc でも閉じる。

popover

popovertarget で開く。外側を押すか Esc で閉じる。

ポップオーバー。最上層に描かれ、モーダルではない。
